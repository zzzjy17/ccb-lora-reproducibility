# 协议 v2：全量微调基线与伪标签真值审计

日期：2026-10-27。代码：`run_experiments.py`，SHA-256 `0a2a486441163489cca25776ebbb4ddc611096dd735fb2e85351da595cbaa35b`。汇总程序：`aggregate_protocol_v2.py`。只使用名称以 `_protocol_v2` 结尾的 50 个正式运行目录；未把旧 208 条记录或 TNEWS smoke test 纳入统计。

## 协议

- 数据集：ChnSentiCorp、TNEWS；各使用 10% 标注训练样本，种子 13、42、2026、7、77。每个种子下五种方法共用同一标注/未标注拆分。
- 方法：普通 LoRA、RC-CCB-LoRA、DCR-CCB-LoRA、标准全量微调、全量微调加 CCB 伪标签。骨干均为 `google-bert/bert-base-chinese`，训练 1 epoch，batch size 16，学习率 2e-5；分类头学习率 5e-4。
- ChnSentiCorp 使用官方 validation 拟合温度，在官方 test 上评价。TNEWS 的 10,000 条有标签 dev 样本按种子分层拆成互斥的 5,000 条校准集与 5,000 条最终评估集。标准 LoRA 和标准全量微调未进行温度缩放；CCB 方法用校准集拟合温度并计算筛选阈值。
- TNEWS 将训练集固定限制为分层抽取的 12,000 条，其中 1,200 条有标签；伪标签候选最多 5,000 条。ChnSentiCorp 使用完整训练集，伪标签候选为各种子未标注部分。保留这些上限是为了与本地重建实验的资源条件一致，因此 TNEWS 结果应标明为 capped protocol。
- 标准全量微调与普通 LoRA 只有一次监督训练；三个 CCB 方法在伪标签筛选后再训练一次。下面的性能比较是最终模型比较，并非训练步数或墙钟时间完全匹配的效率比较。
- 原始训练集标签只用于模拟 10% 分层标注划分和运行完成后的伪标签真值审计。模型训练、温度拟合及伪标签选择均未使用候选样本的真值标签。由于划分曾使用这些标签，不能声称全流程完全没有接触未标注池标签。

## Macro-F1（五个种子，均值 ± 样本标准差）

| 方法 | ChnSentiCorp | TNEWS |
|---|---:|---:|
| 普通 LoRA | 0.8620 ± 0.0102 | 0.2905 ± 0.0420 |
| RC-CCB-LoRA | 0.8804 ± 0.0015 | 0.4313 ± 0.0104 |
| DCR-CCB-LoRA | 0.8811 ± 0.0013 | 0.4419 ± 0.0112 |
| 标准全量微调 | 0.9003 ± 0.0065 | 0.4797 ± 0.0113 |
| 全量微调 + CCB | 0.8927 ± 0.0122 | 0.4945 ± 0.0116 |

DCR 相对普通 LoRA 的配对 Macro-F1 差为 ChnSentiCorp +0.0191、TNEWS +0.1513，两个数据集均为 5/5 个种子正向。相对 RC-CCB-LoRA，配对差分别为 +0.0007 和 +0.0105，均为 5/5 个种子正向；ChnSentiCorp 的差值很小，不能据此宣称有实质性的强优势。

标准全量微调相对 DCR 的配对优势为 ChnSentiCorp +0.0191、TNEWS +0.0378，两个数据集均为 5/5 个种子。全量微调 + CCB 相对 DCR 的配对优势分别为 +0.0116 和 +0.0527，也均为 5/5 个种子。因此，新实验**不支持**“DCR-CCB-LoRA 优于全量微调”或“整体最佳方法”这类表述。方法贡献可表述为在 LoRA 适配框架内相对基线的改进，并同时如实报告全量微调对照。

## 校准误差 ECE（五个种子均值）

| 方法 | ChnSentiCorp | TNEWS |
|---|---:|---:|
| 普通 LoRA | 0.1007 | 0.1744 |
| RC-CCB-LoRA | 0.0554 | 0.0974 |
| DCR-CCB-LoRA | 0.0543 | 0.1028 |
| 标准全量微调 | 0.0305 | 0.0549 |
| 全量微调 + CCB | 0.0511 | 0.1216 |

ECE 比较要注明：两种标准基线使用温度 1.0，CCB 方法执行了温度缩放。DCR 的 ECE 低于普通 LoRA，但并非低于所有方法。温度缩放不保证重训后模型仍保持最小 ECE。

## 伪标签真值审计

把运行中入选的伪标签按原训练集索引与原始标签逐条匹配。该审计在训练结束后进行；它是数据集已有标注的事后核验，不是新增人工复标。下面的 pooled precision 为五个种子的正确数之和除以入选数之和，同一个原始样本可能出现在不同种子中，不能把 pooled 样本当作相互独立的观测。

| 方法 | ChnSentiCorp 正确/入选（precision） | TNEWS 正确/入选（precision） |
|---|---:|---:|
| RC-CCB-LoRA | 2086/2160（0.9657） | 244/278（0.8777） |
| DCR-CCB-LoRA | 2087/2160（0.9662） | 260/302（0.8609） |
| 全量微调 + CCB | 2100/2160（0.9722） | 662/813（0.8143） |

ChnSentiCorp 的 DCR 每个种子选出 432 条；TNEWS 分别选出 83、46、48、64、61 条（种子顺序 13、42、2026、7、77）。TNEWS DCR 的伪标签 precision 高于全量微调 + CCB，但数量少得多，且低于 RC-CCB-LoRA 的 pooled precision。因此不能笼统声称 DCR 伪标签质量最高。质量与覆盖量应同时报告。

## 论文修订边界

1. 用本报告的新协议结果替换原稿 TNEWS 主结果与涉及 TNEWS 的图、表和结论。旧 TNEWS 使用同一 dev 标签拟合温度并评价，不能与 v2 数值并列当作独立测试结果。
2. 增加全量微调和全量微调 + CCB 对照表。明确 DCR 未超过全量微调，不要保留“最佳性能”“全面优于”等旧表述。
3. 写明伪标签真值来自已标注训练集的模拟未标注部分，并给出入选量与 precision。不要称为人工新标注或真实无标签数据的人工验证。
4. 旧 5%/20%、IFLYTEK、消融和敏感性实验仍属于早期协议；如在同一篇论文中保留，应标注其协议差异并重跑受旧校准问题影响的结果。当前 v2 的 10% 两数据集主结果与旧扩展结果不能直接汇成一张同协议表。
5. 这些五种子结果描述均值和波动，不报告未经预先规定或未计算的显著性检验、置信区间或跨数据集统一优势。
